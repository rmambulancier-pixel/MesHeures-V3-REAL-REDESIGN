# MesHeures V3 — Real Redesign

Cette version repart du ZIP original fonctionnel.

## Principe
Le moteur métier `scripts/app.js` n'est pas converti en module et n'est pas remplacé : les calculs et les fonctions existantes restent donc dans leur environnement de fonctionnement original.

## Ce qui est réellement nouveau
- Accueil / cockpit entièrement nouveau
- Carte de journée du jour
- Résumé de période
- Heures supplémentaires
- Brut estimé
- Alertes de période
- Raccourcis
- Vue des 7 derniers jours
- Nouveau header
- Navigation mobile basse
- Nouveau design des cartes et de la journée
- Hero de journée dynamique
- PWA cache versionné V3

## Fonctionnalités historiques conservées
Jour, Mois, Paie, Audit, Bulletin, ROMI1, Réglages, import/export, OCR et PWA.
